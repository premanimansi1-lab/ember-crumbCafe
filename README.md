# EMBER & CRUMB — Café Website Concept

A colorful, editorial café website portfolio concept built with:

- HTML5
- CSS3 with responsive layouts, gradients, texture, hover states, 3D-ready cards and image treatments
- Bootstrap 5.3
- JavaScript
- GSAP + ScrollTrigger
- Magnetic buttons
- Custom cursor
- Scroll progress indicator
- Scroll-to-top interaction
- 3D tilt cards
- Parallax image motion
- Horizontal scroll gallery
- Gallery lightbox modal
- Menu category filtering
- Mobile navigation

## Pages

- `index.html` — animated home
- `menu.html` — filterable menu
- `story.html` — brand story
- `gallery.html` — image gallery + lightbox
- `events.html` — private dining / events
- `contact.html` — enquiry form + WhatsApp placeholder

## Images

The visual version uses real café/food photography from Unsplash via `images.unsplash.com` URLs. The photographs are not fictional/generated placeholders. If this becomes a real client website, keep the image licensing/attribution requirements appropriate to the specific images you choose.

## WhatsApp

Open `js/contact.js` and replace:

`REPLACE_WITH_NUMBER`

with the café's WhatsApp number in international format, without `+`, spaces or dashes.

Example format: `919876543210`

## Important portfolio note

EMBER & CRUMB is a fictional portfolio concept. Menu prices, event descriptions and brand copy are demo content and should be replaced with the real client's information.
